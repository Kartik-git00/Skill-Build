# Skill-Build

Skill-Build is a learning and resource platform.

The initial version focuses on Computer Science.

## Features

- Guest access
- User registration and login
- Learning resources
- Courses and lessons
- Quizzes
- Progress tracking
- Google Analytics
- Python data analysis
- 20–30 day forecasting

## Technology

- Python
- Flask
- HTML
- CSS
- JavaScript
- Supabase
- Google Analytics 4
- Pandas
- Data Science
